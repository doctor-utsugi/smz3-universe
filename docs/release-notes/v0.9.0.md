### Updates

- When a new release is out, the start menu says so and Options gets an Update row at the top.
- Android: Update downloads the new APK and opens the installer. The first time, Android asks you to allow SMZ3 to
  install apps. Your runs stay.
- Linux AppImage (also in Ports), Windows and macOS: Update downloads the new release, puts it in place of the old one
  and restarts.
- 3DS: the menu tells you a new release is out. Copy the new `.3dsx` to the SD card as before.

From this version on you update from inside the app. To get v0.9.0 itself, download it by hand one last time.
