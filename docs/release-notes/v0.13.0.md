### Windows players: update before playing online

Windows builds up to v0.12.0 gave every player the same install id, so the server took all Windows players for one:
they shared gems, world goals and daily attempts, and their ladder times overwrote each other. This version makes a
real id on Windows and replaces the old one. The server no longer accepts the old id, so Windows players need this
version to play online. A run's world goals move to the new id the next time that run reports.

### Three games

- A carousel on the first screen picks SMZ3, A Link to the Past or Super Metroid. Each game keeps its own runs (4 slots
  per game on the 3DS), seeds, daily challenge, ladders, races and world goals.
- A Link to the Past: a port of alttpr's generator with Open, Standard, Inverted and Retro, hunt goals, glitched logic
  and Enemizer boss shuffle. It has alttpr's texts and hints, and the tracker shows the file select hash icons.
- Super Metroid: tewtal's randomizer, and Map Rando (its map, presets and skill levels). Map Rando seeds are made on
  PC and Android; the 3DS gets them from the server.
- Race presets each have their own ladder table: Casual Boots, Standard and AD Keys for ALttP, Map Rando Season 5 and
  Beginner for Super Metroid.
- Cozy runs light the dark rooms in ALttP too.

### Online

- World goals per game: ALttP draws from Zelda and shared goals, Super Metroid from Metroid and shared goals. Gems still
  go to one balance.
- The server checks a Map Rando finish against the seed's own logic.
- The ladder web page has a game switch over the tables.

### Tracker and map

- Single game maps show what the original game has where SMZ3 put its portals.
- Map Rando runs show the game's own pause map.
- Inverted ALttP: Link's House sits in the Dark World, and so does the dot while you are inside it.
- The PC map opens on the game's own half.

### Menus

- Menu music (by Doctor Utsugi, made with Suno) at half volume, fading out when a game starts. Options > Menu music turns it
  off.
- The 3DS downloads and installs new releases itself.
- On the Thor, the bottom screen's tables follow the game picked in the carousel.
