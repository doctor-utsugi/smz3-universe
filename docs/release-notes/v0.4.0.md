### Android phones

SMZ3 now runs on a phone with one screen, not only on the AYN Thor.

- Landscape: the game sits in the middle. The percentage, clock and counters go on the left; crystals,
  bosses and the last items go on the right. R3 opens the tracker over the game. L1 and R1 change tab, and B or
  R3 closes it.
- Portrait: the game is on top with a status line under it. Below that you get the touch pad, or the
  tracker if you tap Tracker in the status line.
- Touch pad: it shows when no controller is connected. In the game menu, Edit Controls lets you drag and
  resize the left and right groups. Each orientation remembers its own layout.
- The tracker's CONFIG tab has a screen mode: Auto, Single or Dual. Auto uses dual only when the second screen
  is built into the device, so a cast screen or an HDMI cable doesn't count.
- The community sprites come inside the APK, so the sprite pickers work without copying a folder to the SD card.
  The Original Link and Samus are drawn from your ROMs.
- In portrait the menus use the whole height of the phone: more runs in the list, more sprites per page and
  more rows in the option lists.
- A game starts even if you don't allow notifications.

### Linux: two screens

On a handheld with two screens (the Anbernic RG DS, for example), the game goes on the top screen. The bottom
screen always shows the tracker, and tapping a tab opens it. Video settings have a new Screens option (Auto,
Single or Dual). Auto picks dual on an RG DS or when both displays are handheld sized. This is new and hasn't
been tried on a real RG DS yet.

### Menus

- In a 4:3 window the Daily and World goals cards no longer overlap their own text.
