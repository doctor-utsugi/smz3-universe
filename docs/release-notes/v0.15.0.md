### Cloud sync with RomM

- Options > Cloud sync signs the device in to a [RomM](https://romm.app) server with a short code you approve on
  RomM's page. Your runs, in-game saves and save states then follow you between the PC, Android and the 3DS.
- Continue brings down whatever another device changed; leaving a run sends your changes up. If a run changed on two
  devices, the app asks which one to keep and shows where and when the other change was made.
- Runs made on another device show up in free slots. Deleting a run removes it from RomM too.
- Link another device / Enter a link code joins two devices into one player: the same name, gems, world goals and
  ladder entries on both.
- Only saves and states written by SMZ3 count for the ladders. A file from another emulator keeps playing, unranked.

### Save states

- Android now runs the same snes9x core as the PC, so states move between them. States made by older Android builds
  still load.
- The 3DS converts its states to and from that format when it syncs. Its state slots go from 5 to 4, like the other
  devices.
- PC: deleting a run also deletes its quick states.
