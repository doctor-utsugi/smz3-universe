### New run

- Custom runs open on a new Quick tab with the options most players change: game mode, keysanity, wall jump logic,
  helps, lit dark rooms, quick morph, save states, rewind and reachable checks. Every option is still in its own tab.

### Online

- Only runs with the randomizer's own rules, monthly runs and weekly runs go to the online ladder. Cozy and custom
  runs stay on the device, and the Start screen says so. A Cozy run now always has rewind, even when you play online.

### Android

- A paused rewind holds its frame. Before, it flickered between two pictures.

### Linux

- A build for ARM (aarch64), `SMZ3-aarch64.AppImage`, for handhelds and boards. It hasn't been tried on a handheld
  yet.
