### 3DS

- SMZ3 now keeps its files in `sdmc:/3ds/SMZ3/`, and the ROMs go straight in that folder. If you had an `SMZ3`
  folder at the root of the card, the app moves it there the first time it opens, with your runs and saves.
- The Plando help names the new folder.

### macOS

- SDL2 is now inside the `smz3` binary, so you don't need Homebrew to run it.
