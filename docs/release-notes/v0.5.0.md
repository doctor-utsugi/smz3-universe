### Rewind

Runs have a new Rewind option in the QoL tab, off by default. Only offline runs can use it; ladder and daily
runs never rewind. A run without the option keeps nothing, so it costs no memory or time.

- Opening rewind freezes the game on the current frame, which stays as bright as it was. A bar under it shows
  how far back you are.
- Hold back or forward to move. It starts at real speed, then goes twice and four times as fast. A plays on
  from that moment and B goes back to the present.
- The game clock keeps running while you rewind. The tracker drops what the rewind undid, the same as after
  loading a state.
- Opening, moving and closing each have a sound.

Where to find it:

- PC: R on the keyboard or LT on a pad. You can rebind it under controls. Fast forward can now be rebound
  on the keyboard too (Space by default). Up to a minute is kept, one frame at a time.
- Android: L2 + L1, which you can change in the tracker's CONFIG tab. With touch controls there's a rewind
  button at the bottom of the picture, and the bar has touch buttons. Up to a minute is kept, one frame at a time.
- 3DS: the RW button on the save bar, between LOAD and fast forward, or ZL, ZR or the C-stick if you bind
  it in the game menu. The bottom screen shows the controls while rewinding. It keeps a state every 10 frames
  on a New 3DS and every 30 on an Old one, so going back looks like a flipbook. This hasn't been tried on a
  real console yet.
