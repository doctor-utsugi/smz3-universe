### 3DS

- SMZ3 now comes as a CIA too. Install `SMZ3-3ds.cia` with FBI and it shows up on the HOME menu with its own icon and
  banner. The `.3dsx` for the Homebrew Launcher is still there.
- The community sprites come with the app: 517 for Link and 216 for Samus, with nothing to copy to the SD card.
  Sprites of your own in `3ds/SMZ3/sprites` still show up, and one with the same name as a bundled sprite replaces it.
- The online parts (daily challenge, world goals, ladders) work on a real console. Before, the 3DS could not open a
  secure connection to the server and showed Offline.
- With the console off the network, the run list says Offline at once instead of staying on "Connecting...".
- The 1px line over the Super Metroid HUD is gone. It was the SNES's first line, which a real SNES never shows.
