### 3DS

- The app opens straight into SMZ3, with the same menus, tracker and Game menu as the Thor. Nothing of the emulator
  shows. It runs on the Old 3DS, and making a run takes less than half the memory it used to.
- The RUN tab has a SAVE / LOAD / fast forward bar. Fast forward also runs while the 3D slider is up.
- On a New 3DS, ZL, ZR and the C-stick can be bound to fast forward, save, load, the Game menu or an item shortcut.
- In a run without save states, tapping SAVE or LOAD shows why for 3 seconds.

### Everywhere

- The daily challenge shows on the RUN tab how many players are on it now, how many started and how many finished.
  Every 10 minutes a note says how many are playing. Its hints moved to HELP, and the DAILY tab is gone.
- A daily could end as complete the moment it opened. Fixed.
- Weekly and monthly runs show the crystals and bosses they ask for on the RUN tab, in place of the completion bars.
- Each run's card shows the Link and Samus sprites you picked.
- The tracker boots up like Samus's visor when a game opens, and a portal opens when you cross between Zelda and
  Metroid.
