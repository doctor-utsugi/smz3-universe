### Online

- New server address: smz3-universe.duckdns.org. Ladders, daily challenges and races start again from zero there.
- Races: one kind of room for 2 to 8 players, started by its creator. With two players it plays the 1 vs 1 rules.
- Races: the game holds its first frame until the countdown reaches zero on every version, and the server clock is
  taken from the quickest round trip.
- Races: an open room whose creator left is no longer listed, and a room nobody asks about for 3 minutes before the
  start is cancelled.

### Tracker

- On a game change the map switches to the new game's side: Samus's last place, or the middle of the Super Metroid
  side, instead of the other game's old spot.

### PC

- Every action takes a keyboard key, including the tracker, leave and states.
- Each collected check in the tracker says what it gave in this seed.
- The tracker opens the options (O / Start) over the stopped game.
- The mouse pointer hides while the game moves and the mouse is still.

### 3DS

- A run that shows reachable checks marks them on the map: amber for reachable, grey for needs items. The next
  reachable spot sends out an amber ring.
- A tap stays a tap unless the finger moves 12 px, so the screen's jitter no longer turns taps into drags.
- A button row binds its own button in one press.
- What failed online (seeds, ladders, daily) is asked again every 10 s, so Offline clears once the wifi joins.
