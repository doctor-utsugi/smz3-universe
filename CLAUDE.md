# SMZ3 Universe: rules for agents

## Releases

Never release a version without asking the owner (Doctor Utsugi) first, every time. Pushing a `v*` tag makes CI publish a
GitHub release for every platform, and the owner decides when that happens. Committing and pushing to `main` is fine;
tagging, creating a GitHub release and bumping the version for a release need the owner's yes for that specific release.
